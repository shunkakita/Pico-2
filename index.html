Overview

What is this project?

In this project, I created an automatic lid opener using the Raspberry Pi Pico and related components. Prior to making the actual lid opener, I went through preliminary steps to showcase different components individually and in combinations.

Goals

Goals of the project

  • Task 1 – Tilt switch without code
  • Task 2 – Tilt switch with code
  • Task 3 – A sun track using LDRs, servos, and LEDs
  • Main goal - Create an automatic lid opener
How It Works

How it works

Step 01

For this task, there was no code involved, I only had to connect the Pico to a power source. To do this, I made sure the wires were connected to a powered pin.

Step 02

For this task, I created the same tilt switch LED activation system, btu this time using code. This code is very simple – I set each pin to the components and made it read the tilt switch value and have the LED show it.

Step 03

For this task, I created a sun tracker using the LDRs, an LED, and the servo. The system senses which LDRs are covered, and when the left one is covered, the servo moves in one direction and the LED turns off, and vice versa. If they are both covered, the LED blinks. Idle, the LED is on.

Step 04

For the final goal of creating the automatic lid opener, we had to incorporate an obstacle avoidance module, acting as the sensor to toggle the servo, and a potentiometer, which set how far the servo opens. In the code, I defined the angles and the readings from the sensor and set each value and related them in order to make the servo function as intended.

How It Was Made

How it was made

Step 01

For this task, I had to configure it in a way where the connection of the power to the LED would go to zero once the tilt switch was triggered. To do so, I connected the resistor from the LED to the LDR, which is where the current shifts. In order for this to run without code, I used the power pins instead of GP pins.

Step 02

This task had the same premise as the first, but it allowed code. The only difference in this structure is where the power is coming from. The pins are connected to GP pins, which need to be coded.

Step 03

To create the system, I did basic wiring for the servo and combined the two LDR and LED systems with the resistors and wires. I connected each wire to its respective position.

Step 04

To create this system, I wired the servo and sensor to their respective pins, and connected each component using wires, where the sensor and the potentiometer were integrated into the same current coming from the power.
